# Mission Framework Visual Language

This directory contains governed visual models used across the Mission Framework book, Publication Hub and presentation profiles.

## Principles

- Visuals must clarify meaning rather than decorate it.
- Canonical concepts remain defined in Markdown.
- Every diagram should be understandable without relying on colour alone.
- Book versions may contain more detail than presentation versions.
- SVG is the canonical rendered format because it scales cleanly across web, PDF and slides.

## Initial visual set

1. `mission-framework-overview.svg` — framework context and core relationships.
2. `mission-loop.svg` — the iterative mission cycle.
3. `reality-evidence-decision.svg` — how reality, evidence, decision and action remain connected.
4. `publication-pipeline.svg` — how canonical knowledge becomes audience-adapted publications.

## Style tokens

- Navy: `#13254A`
- Blue: `#2457D6`
- Pale blue: `#EAF0FF`
- Text: `#182033`
- Muted: `#5F6B7A`
- Line: `#D9E1EC`

Generated publications may embed these SVG files directly. Semantic changes belong in the source model and accompanying documentation.
